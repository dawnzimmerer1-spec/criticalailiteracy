# Critical AI Literacy

Source files for [criticalailiteracy.net](https://criticalailiteracy.net), a research, teaching, and practice hub focused on critical AI literacy in higher education.

## Site structure
- `index.html` — main site
- `assets/styles.css` — visual design and responsive layout
- `assets/script.js` — accessible mobile navigation and footer year
- `CNAME` — GitHub Pages custom domain configuration
- `404.html` — custom not-found page

## Publishing with GitHub Pages
This site is designed to publish directly from the repository root on the default branch using GitHub Pages.
